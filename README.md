# 截图打码（工作名）

端侧自动识别截图里的敏感信息并打码。全部用系统自带的 Vision / Core Image，不联网、不上传、不收集数据。

## 入口

| 入口 | 用法 |
|---|---|
| App | 打开即进入最新一张未打码的图片并开始识别 → 审核 →「导出」（格式 / 大小 / 水印 / 删原图 + 保存或分享）；返回是相册网格，可多选批量 |
| 分享扩展 | 截图后点缩略图 →「分享」→「截图打码」→ 审核 → 保存（保存后扩展自动关闭） |
| 快捷指令 | 动作「打码图片」：不打开 App，返回打码后的图片 |

**一键打码最新截图（推荐配方）**：快捷指令 → 新建 →「获取最新截屏」→「打码图片」→「保存到"照片"」→（可选）「删除照片」删掉原图 →
设置 › 辅助功能 › 触控 › 轻点背面，绑定这个快捷指令。这样 App 自己不需要读取相册，删原图交给快捷指令自带的动作（系统会确认）。

## 结构

```
Package.swift            RedactKit（核心库）+ RedactUI（App 与分享扩展共用的界面），iOS 17+ / macOS 14+
Sources/RedactKit/
  Rules/                 文本规则：归一化（全角、O→0、分组空格）+ 校验（身份证校验码、Luhn）+ 关键词定位
  Detection/             Vision（OCR / 人脸 / 条码，长截图分段）+ 聊天布局分析（头像 / 昵称 / 标题 / 系统消息）
  Render/                Core Image 打码、水印、导出尺寸 / 格式、无元数据编码、截图 / 照片判断
Sources/RedactUI/        审核页（双指缩放、点框开关、长按单独换效果、手动补框）、效果面板、导出选项、EXIF 查看、相册读写
Sources/ChatSynth/       合成仿微信聊天截图（带精确标注），用来量化头像 / 昵称的召回率
Sources/redact-cli/      macOS 命令行：批量识别、输出标注图 / 打码图、跑评估
Tests/                   规则、渲染（贴边模糊、叠加翻出、抹除残留）、导出（水印、尺寸、三种格式无元数据）、布局回归
App/Redact/              App 主程序 + 快捷指令动作（Intents/）
App/RedactShare/         分享扩展
Tools/icon/               App 图标生成脚本：swift Tools/icon/render-icon.swift App/Redact/Assets.xcassets/AppIcon.appiconset bubble
testdata/                本地测试图（不入库；fixtures/with-gps.jpg 是用来测 EXIF 的合成图）
```

## 常用命令

```bash
swift test                                              # 单元测试
swift build -c release
.build/release/chat-synth testdata/synthetic 60         # 生成 60 张合成聊天截图
.build/release/redact-cli eval testdata/synthetic       # 头像 / 昵称 / 标题 / 系统消息的召回率与精确率
.build/release/redact-cli detect 某张截图.png --out testdata/out   # 输出 .overlay.png 和 .redacted.png
```

iOS App：用 Xcode 打开 `App/Redact.xcodeproj`，或

```bash
xcodebuild -project App/Redact.xcodeproj -scheme Redact -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' build
```

## 关键设计

- **效果可选**：自动 / 抹除文字 / 色块 / 杂讯色块 / 像素化 / 模糊 / 彩虹条 / 彩虹格，色块类可选颜色，
  选择会被记住；长按单个框可以单独换效果（优先级：单处 > 全局 > 类别默认）。
  色块、杂讯色块、彩虹条、彩虹格只由区域位置和颜色生成，不读原图——有测试保证两张不同原图打码后区域像素完全相同。
- **打码不可逆且不泄露**：文字默认"抹除"——背景够纯就用背景中位色填平，否则大块像素化（块 ≥ 半个字高）；
  每处都从当前结果取像素（后加的效果不会翻出先前的遮挡）；`clampedToExtent()` 防止贴边模糊透出原图。
- **导出**：顺序固定为 打码 → 水印 → 缩放，缩小不会削弱打码。格式"自动"时截图用无损 PNG、照片用 HEIC；
  「照片」分享出来的截图是转码后的 JPEG，所以按 EXIF 判断（没有快门 / 光圈即截图）。任何格式都不写入原图元数据。
- **号码写法**：两遍扫描（保留 / 去掉数字间分隔符），既能命中 `6222 0212 3456 7894`，又能拆开相邻的两个号码；
  折行的邮箱、单号把上下两行拼起来再扫。
- **头像**：带状搜索——枚举"离边缘 s、宽 bw"的竖带，找高≈宽、带内前景过半、内侧间隙是背景的行段。
  不依赖分割，所以头像和气泡粘在一起、有弹窗 / 卡片干扰时也能找到。
- **昵称**：头像右侧、顶部对齐、落在页面背景上（不在气泡里）的 OCR 行；
  另有"昵称列"推断和像素兜底，OCR 漏掉短而淡的昵称时也能补上。
- **权限**：首次打开申请相册访问，系统弹窗可选「允许完全访问 / 选择照片（受限）/ 不允许」。
  受限时只显示允许的照片，并提供"选择更多"；拒绝时仍可用系统选择器手动选图。保存只写入、不读取。
- **不重复进入**：导出文件名带 `-redacted.` 标记，网格里显示"已打码"，打开 App 时跳过这些图和已保存过的原图；
  从后台回来时只有出现了新的待打码图片才会自动跳转，不会打断正在编辑的图。
- **分享扩展内存**：扩展的内存上限远小于 App，所以最多 10 张、显示图长边 ≤ 2048、串行识别；识别和导出仍用原图。

## 已知限制 / 下一步

- 分享扩展和 App 的偏好（效果、颜色、导出选项）各自独立；要共享需配 App Group（需要签名团队）
- 快捷指令里的"打码图片"跟随 App 的导出选项（格式、尺寸、水印），但不做删除原图
- 照片编辑扩展（在「照片」里直接编辑）还没做
- 朋友圈点赞 / 评论区里的名字；被导航栏遮住一半的头像
- 截图外面套了设备边框的宣传图（页面背景色估计会错）
- 真实截图测试集太小（网上的聊天截图大多已打码），需要自己补充
